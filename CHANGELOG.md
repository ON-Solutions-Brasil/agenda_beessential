# Changelog

Todas as mudanças notáveis deste projeto serão documentadas neste arquivo.

## [1.0.0] - 2026-07-30

### Adicionado
- Estrutura MVC completa do projeto
- Sistema de autenticação (login/logout)
- Painel de superadmin com permissões granulares
- CRUD de usuários com roles e permissões
- Sistema de agendamento de reuniões
- Calendário com visualização por dia, semana e mês
- Geração automática de links do Google Meet
- Tela de configurações do sistema
- Migrations SQL para criação do banco de dados
- Layout responsivo com Bootstrap 5
